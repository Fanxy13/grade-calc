# Notenrechner

Ein einfacher Notenrechner als statische Website.

## Unterstützte Systeme

- Schweiz: 1–6
- Deutschland: 1–6
- Österreich: 1–5
- Frankreich: 0–20
- USA: GPA 0–4
- Grossbritannien: Prozent 0–100

## GitHub Pages

1. Alle Dateien in ein GitHub-Repository hochladen.
2. Repository öffnen.
3. `Settings` → `Pages`.
4. Bei `Build and deployment` → `Source` **Deploy from a branch** auswählen.
5. Branch `main` und Ordner `/ (root)` auswählen.
6. Speichern.

Die Noten und gespeicherten Ergebnisse werden nur mit `localStorage` im jeweiligen Browser gespeichert.
